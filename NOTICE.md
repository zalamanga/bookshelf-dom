# Asal source dan aset

Proyek ini melanjutkan latihan `tugas-dom-dicoding/app` dari koleksi kerja pemilik repository. Perilaku awal meliputi tambah buku, pencarian, pindah rak, hapus, dan penyimpanan `BOOKSHELF`.

`assets/img/book.png` mempertahankan gambar Buka Buku dari source awal tanpa mengubah byte gambar. Tidak ada logo baru yang dibuat. Referensi `buku.png` yang tidak tersedia tidak digunakan kembali.

Source JavaScript dipisah menjadi logika data dan penghubung DOM. Perapihan menambahkan edit, unduhan JSON, validasi data lama, pemulihan storage, pengamanan teks DOM, kontrol bernama, fokus keyboard, dan tata letak responsif.

Aplikasi ini mandiri di browser; aplikasi Java Buka Buku pada koleksi yang sama merupakan proyek berbeda. Screenshot menggunakan buku contoh pengujian dan tidak menyertakan data pribadi.

Tidak ada lisensi baru yang ditetapkan untuk aset lama yang asal lisensinya tidak tercatat dalam source. Dependency pengujian Playwright mempertahankan lisensi upstream-nya.
